## 注意事項

1. 爬蟲需設置合理請求間隔（建議 ≥ 2 秒）
2. 官方數據有發布延遲，通常滯後 1–2 個月
3. 各來源欄位格式唔同，需透過 ETL 藍圖統一
4. 敏感配置（API key）放 `.env`，唔入 git
